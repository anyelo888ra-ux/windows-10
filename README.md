# 💻 Windows 10 Web Simulator Collection

Colección de simuladores web de **Windows 10** desarrollados en HTML, CSS y JavaScript vanilla por distintas IAs.

🚀 **Prueba la demo en vivo:** [https://anyelo888ra-ux.github.io/windows-10/](https://anyelo888ra-ux.github.io/windows-10/)

---

## 🖥️ Versiones disponibles

| Versión | Archivo | Características principales |
| :--- | :--- | :--- |
| **DeepSeek Edition** *(Principal)* | `windows 10 deepseek.html` | Cobertura masiva de código (+6000 líneas), alta complejidad y detalles en apps internas. |
| **Claude Edition** | `Windows 10 claude.html` | Estética pulida y fluidez en el manejo de ventanas. |
| **Gemini Edition** | `windows 10 gemini.html` | Enfoque ligero, rápido e integración con audio API y componentes dinámicos. |

---

## 🛠️ Tecnologías utilizadas

* **HTML5 / CSS3** (Efectos Blur, Grid y Flexbox)
* **JavaScript Vanilla** (Gestor de ventanas z-index, LocalStorage y manipulación del DOM)
* **Web Audio API** (Efectos de sonido del sistema)
* **Canvas API** (Aplicaciones de dibujo y Paint)
